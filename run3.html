About Run 3

Run, jump, and tumble through tunnels in space. Guide your explorer along the walls of crumbling tubes — fall off the edge and the run is over. Unlock characters and paths in this classic Flash endless runner.

Original Creator: Player 03
First Released: 2014
Version on site: Classic Flash (Ruffle emulator)
Added to Unblocked Game Galaxy: October 2026

Controls:
• Arrow keys / WASD — move and jump
• Stay on the tunnel walls — falling into the void ends the run
